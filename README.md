## Muestras de código

[Ver las tres demos originales y sus pruebas](https://github.com/agustincastillo5822-coder/portfolio-demos)

- **Panel web:** interfaz en Next.js y React con filtros por texto y estado sobre datos ficticios.
- **API de automatización:** validación de solicitudes, persistencia en SQLite y deduplicación mediante claves de idempotencia.
- **Verificador documental:** cálculo y comparación local de SHA-256, sin subir archivos.

Desarrollé estas demos con asistencia de IA para mostrar implementaciones concretas. Incluyo instrucciones, pruebas y límites documentados. No las presento como trabajos para clientes ni productos desplegados. Verifiqué las pruebas locales, TypeScript y la compilación; todavía tengo pendiente la validación visual y de interacciones en navegador.
