### Capa Cero

Participo en la construcción de una plataforma y fábrica de productos digitales para empresas e instituciones. El sitio presenta soluciones de cobros, documentos, comunicación, automatización e integraciones, con estados de disponibilidad diferenciados.

[Conocer Capa Cero](https://capacero.ar/)

En el [catálogo público del ecosistema](https://capacero.ar/productos) presento los productos con su disponibilidad declarada, no como una certificación de todas sus operaciones:

- **Negocios:** hub de perfiles, módulos y procesos. Disponible y funcionando según el catálogo.
- **Switch:** cobros y conciliación. Disponible bajo implementación.
- **Cero Partners:** operaciones comerciales B2B. Disponible bajo implementación.
- **ADDA:** confianza técnica y defensa perimetral. Disponible bajo implementación.
- **WhatsApp Cero:** operaciones desde conversaciones. Disponible bajo implementación.
- **Red Cero:** directorio y activación comercial. Disponible bajo implementación.
- **Economic Protocol:** unidades de trabajo para agentes. Piloto.
- **Conecta:** integración y normalización de datos. Piloto.

Cada activación conserva sus requisitos de configuración, permisos y validación. No publico código ni datos de estas implementaciones.
