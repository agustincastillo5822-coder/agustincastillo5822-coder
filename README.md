# Agustín Ignacio Castillo

Desarrollo productos digitales con asistencia de IA desde 2025. Trabajo en producto, automatización e integraciones, y convierto ideas en implementaciones concretas.

## Mi código

En [mi portfolio de demos](https://github.com/agustincastillo5822-coder/portfolio-demos) comparto ejemplos originales con código, instrucciones y pruebas:

- **Interfaces web:** construyo un panel con Next.js, React y TypeScript, filtros y estados de interfaz.
- **APIs y automatización:** valido solicitudes, persisto datos en SQLite y evito duplicados mediante claves de idempotencia.
- **Verificación documental:** calculo y comparo huellas SHA-256 con procesamiento local de archivos.
