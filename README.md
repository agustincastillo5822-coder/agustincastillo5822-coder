Trabajo en producto, automatización e integraciones. Este es mi perfil personal: reúne muestras de código y enlaces a proyectos, manteniendo separados sus repositorios y sus identidades.

## Muestras de código

[Ver las tres demos originales y sus pruebas](https://github.com/agustincastillo5822-coder/portfolio-demos)

- **Panel web:** interfaz en Next.js y React con filtros por texto y estado sobre datos ficticios.
- **API de automatización:** validación de solicitudes, persistencia en SQLite y deduplicación mediante claves de idempotencia.
- **Verificador documental:** cálculo y comparación local de SHA-256, sin subir archivos.

Son demos desarrolladas con asistencia de IA para mostrar implementaciones concretas. Incluyen instrucciones, pruebas y límites documentados. No representan trabajos para clientes ni productos desplegados. Las pruebas locales, el chequeo TypeScript y la compilación están aprobados; la validación visual y de interacciones en navegador sigue pendiente.
